Thesis on VR interface

This is the Thesis that I wrote for my Bachelor's degree in Information Technology. In this project I developed several User Interface that allow users to select an item in a serious game while running on a virtual platform.

These are the final User Interface that were used in the gameplay, chosen between 8 different interface that I developed.

This project was developed with the HTC Vive Pro VR headset and controllers, the KAT WLK Mini S treadmill and Unity.
